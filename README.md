SENTINEL is a prototype of a turn-based tower defense game where you defend the last stronghold of humanity against supernatural creatues.

During the build phase, the player will be able to spend their accumulated resources to build new towers.
Each tower has both a main and a secondary ability.

During the battle phase, the player and enemy take turns.
Enemies move closer each turn and activate their own abilities, buffing each other and attacking the player's towers.
On the player's turn, they receive a limited number of activation points, which they can use on their towers.
Activating a tower uses its primary ability; however, it also activates nearby towers' secondary abilities.

Based on the positioning of built towers and strategic usage of activation points, the player can both defend themself and gather new resources for the next build phase.
